# WebGIS Dashboard

A lightweight WebGIS application displaying Indian state boundaries with stats and search using Leaflet.js.

## Features

- Leaflet map with Indian state boundaries
- Popups on click with state name
- Sidebar with:
  - Total number of states
  - 5 random states with population
  - Search bar to highlight and show info
- Responsive layout using Flexbox

## Setup

1. Clone or download this repo
2. Make sure the `india_states.geojson` file is placed in the `data/` folder
3. Open `index.html` in a browser

## Tools Used

- [Leaflet.js](https://leafletjs.com/)
- OpenStreetMap tiles
- HTML/CSS/JavaScript
